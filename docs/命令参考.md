# lan-link 命令参考（中文）

> lan-linkctl — 局域网远程管理客户端
> 通信目标: 192.168.31.244:9876 | 加密: ChaCha20-Poly1305

---

## 全局选项

| 选项 | 默认值 | 说明 |
|------|--------|------|
| --addr / -a | 192.168.31.244:9876 | 目标 daemon 地址 host:port |
| --psk / -p | (内置 32 字节 hex) | 32 字节 PSK hex 字符串 |

---

## 命令执行

### exec — 远程执行命令
`
lan-linkctl exec 'ls -la /root'
lan-linkctl exec 'df -h'
lan-linkctl exec 'systemctl status nginx'
`
等待命令执行完成后输出结果。支持管道 stdin（Python 客户端）。

### iexec — 交互式执行
`
lan-linkctl iexec bash
lan-linkctl iexec 'top -b -n1'
`
支持 stdin 双向通道，可以在执行过程中输入内容。退出后会显示退出码。

### shell — 交互式 shell 会话
`
lan-linkctl shell
`
完整的交互式 bash 会话，适合长时间操作。

### batch — 从文件批量执行命令
`
lan-linkctl batch setup.txt
`
文件每行一条命令，# 开头为注释。自动统计成功/失败数量，显示退出码和超时信息。

### watch — 每隔 N 秒重复执行
`
lan-linkctl watch -e 5 'df -h /'
lan-linkctl watch -e 2 'ss -tln'
`
适合监控场景，每次执行前显示时间戳和序号。

## 文件操作

### ls — 列出远端目录
`
lan-linkctl ls /var/log
lan-linkctl ls -la /etc
`
-l 详情模式，--all 显示隐藏文件。

### cat — 显示文件内容
`
lan-linkctl cat /etc/hostname
lan-linkctl cat /var/log/syslog
`

### head — 文件开头 N 行
`
lan-linkctl head -n 20 /var/log/syslog
`

### tail — 末尾行或实时跟踪
`
lan-linkctl tail -n 50 /var/log/syslog
lan-linkctl tail -n 50 -f /var/log/syslog
`
-f 实时跟踪模式（类似 	ail -f）。

### find — 查找文件
`
lan-linkctl find /etc --name '*.conf'
lan-linkctl find /var --type f --name '*.log' --maxdepth 5
`
支持 --name 模式匹配、--type 文件类型、--maxdepth 最大深度。

### grep — 搜索文件内容
`
lan-linkctl grep -rn 'error' /var/log
lan-linkctl grep -c 'ERROR' /var/log/syslog
`
-r 递归，-n 显示行号，-c 只统计匹配行数。

### du — 磁盘用量
`
lan-linkctl du -sh /home
lan-linkctl du /var --maxdepth 2
`
-s 汇总模式，--maxdepth 最大深度。

### df — 磁盘分区使用
`
lan-linkctl df -h
lan-linkctl df -h -a
`

### tree — 目录树
`
lan-linkctl tree /etc --depth 3
lan-linkctl tree /var --dirs-only
`
远端需安装 	ree 命令。--dirs-only 只显示目录。

### stat — 文件元信息
`
lan-linkctl stat /etc/passwd
`

### diff — 比较两个文件差异
`
lan-linkctl diff a.txt b.txt
`

### wc — 行数/字数统计
`
lan-linkctl wc -l /var/log/syslog
lan-linkctl wc -w /var/log/syslog
`

## 文件传输

### push — 上传本地到远端
`
lan-linkctl push -l config.json -r /tmp/config.json
lan-linkctl push -l myapp.tar.gz -r /tmp/myapp.tar.gz
`
分块加密传输，自动处理大文件。

### pull — 下载远端到本地
`
lan-linkctl pull -r /var/log/nginx/access.log -l access.log
lan-linkctl pull -r /etc/hosts -l hosts.txt
`
通过 base64 编码传输，显示下载进度。

## 进程管理

### ps — 列出进程
`
lan-linkctl ps
lan-linkctl ps --tree
lan-linkctl ps --user root
`
-f 全格式，--tree 树形，--user 按用户过滤。

### kill — 终止进程
`
lan-linkctl kill 1234
lan-linkctl kill 1234 -s 9
`
默认 SIGTERM(15)，-s 指定信号号。

### pgrep — 按名称查找进程
`
lan-linkctl pgrep nginx
lan-linkctl pgrep -f nginx
`
-f 全命令行匹配，-c 只计数。

### pkill — 按名称杀进程
`
lan-linkctl pkill nginx
lan-linkctl pkill nginx -s 9
`

### top — 循环显示进程排名
`
lan-linkctl top --interval 3 --iterations 5
`
使用 	op -b -n1 -c 获取更准确的进程信息。

### signal — 给运行中的 exec 发信号
`
lan-linkctl signal 1 9
`
对已启动的 exec id 发送信号（需配合 iexec/shell 使用）。

## 网络

### ping — RTT 延迟测试
`
lan-linkctl ping --count 10
`
测试客户端到 daemon 的网络延迟，显示 min/avg/max。

### netstat — 网络连接
`
lan-linkctl netstat -tln
lan-linkctl netstat -uan
`
-t TCP，-u UDP，-l 只显示监听，-n 不解析名称。

### ip — 网络接口
`
lan-linkctl ip --addr
lan-linkctl ip --route
lan-linkctl ip --link
`

### portscan — TCP 端口扫描
`
lan-linkctl portscan 127.0.0.1 --start-port 1 --end-port 1024
`
通过 bash /dev/tcp 实现，无需额外工具。

### arp — ARP 表
`
lan-linkctl arp
`

### dns — DNS 解析
`
lan-linkctl dns google.com --type A
`

### ssh — 检查 SSH 监听
`
lan-linkctl ssh
`

`

`

`
lan-linkctl service status nginx
`

`

`

### service enable/disable — 自启管理
`

`

`

`
-u 指定 unit，-p 日志级别，-f 实时跟踪，--since 时间范围。

## Python 客户端

Python 客户端（client_win.py）是轻量替代方案，适合快速执行命令。

`
python client_win.py exec 'ls -la'
python client_win.py exec 'df -h'
echo 'test' | python client_win.py exec cat
python client_win.py --show-config
python client_win.py --write-config
`

### 配置

配置文件: %APPDATA%\lan-link\config.json

| 选项 | 默认值 | 说明 |
|------|--------|------|
| addr | 192.168.31.244:9876 | daemon 地址 |
| psk | ca989e3c... | 32 字节 hex 密钥 |
| heartbeat_interval | 10.0 | 心跳间隔秒数 |
| reconnect_backoff | [0.5, 1, 2, 5, 10] | 重连退避策略 |

## 场景速查

| 需求 | 命令 |
|------|------|
| 看看远端什么情况 | lan-linkctl info |
| 看进程 | lan-linkctl top |
| 看日志 | lan-linkctl tail -f /var/log/syslog |
| 搜日志 | lan-linkctl grep -rn 'error' /var/log |
| 拿个文件 | lan-linkctl pull -r /path/to/file -l file |
| 传个文件 | lan-linkctl push -l file -r /path/to/file |
| 配个服务 | lan-linkctl service restart nginx |
| 装个包 | lan-linkctl pkg install nginx |
| 看 Docker | lan-linkctl docker ps -a |
| 端口通不通 | lan-linkctl portscan 192.168.1.1 --end-port 100 |
| 延迟多少 | lan-linkctl ping -c 10 |
| 批量执行 | lan-linkctl batch cmds.txt |
